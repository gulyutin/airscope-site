# airscope.ru

Посадочная страница платформы AirScope (модули AirBIM, AirInfra, AirHeritage). Разработка ИКИТ СФУ.

Сайт статический: всё, что публикуется, лежит в папке `site/`.

## Как работает выкладка

Каждый пуш в ветку `main`, который меняет `site/`, запускает GitHub Actions (`.github/workflows/deploy.yml`). Действие копирует папку `site/` на хостинг REG.RU по FTPS и передает только изменившиеся файлы. Выкладку можно запустить и вручную: вкладка Actions → «Выкладка на airscope.ru» → Run workflow.

## Настройка (один раз)

1. В панели REG.RU привязать домен `airscope.ru` к услуге хостинга.
2. В панели хостинга взять реквизиты FTP: адрес сервера, логин и пароль.
3. В репозитории открыть Settings → Secrets and variables → Actions и добавить секреты:
   - `FTP_SERVER` — адрес FTP-сервера хостинга;
   - `FTP_USERNAME` — логин FTP;
   - `FTP_PASSWORD` — пароль FTP.
4. Если папка сайта на хостинге называется иначе, чем `www/airscope.ru/`, добавить на вкладке Variables переменную `FTP_DIR` с путем к ней (со слешем в конце).
5. Если хостинг не принимает защищенное соединение, добавить переменную `FTP_PROTOCOL` со значением `ftp`.

Пароли в репозиторий не записываются: они хранятся только в секретах GitHub.

## Локальный просмотр

Открыть `site/index.html` в браузере.
